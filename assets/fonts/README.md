# 넥슨 풋볼고딕

[넥슨 공식 배포본](https://brand.nexon.com/resources/NEXON_Football_Gothic.zip)의 `OTF/NEXON Football Gothic L.otf`와 `OTF/NEXON Football Gothic B.otf`를 각각 `NEXONFootballGothic-Light.otf`, `NEXONFootballGothic-Bold.otf`라는 파일명으로 포함합니다. 파일 내용은 수정하지 않았습니다.

- 사용량: Bold, 9pt
- 초기화 시간·날짜: Light, 9pt
- 우클릭 메뉴: Tk 기본 메뉴 크기·스타일을 유지하고 글꼴 종류만 Light로 변경
